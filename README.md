# FlowWing GRC Risk Assessment

An independent information-security risk assessment for **FlowWing Solutions**, a fictional SaaS organization.

## Project Overview

This project demonstrates the identification, analysis, evaluation, and treatment of information-security risks using a likelihood-impact scoring methodology.

## Current Risk Register

- **R1:** Unauthorized Production Access
- **R2:** Loss or Corruption of Customer Data

## Assessment Coverage

The assessment currently includes:

- Organizational context and assessment scope
- Risk-assessment methodology
- Inherent likelihood and impact ratings
- Risk ownership and response strategies
- Recommended security controls
- Residual-risk considerations
- Planned alignment with ISO/IEC 27001:2022 Annex A

## Project Status

This project is currently **in progress**. Additional risks, control mappings, and residual-risk assessments will be added in future updates.

## Disclaimer

FlowWing Solutions is a fictional organization created solely for this independent portfolio project.
